# Conversor de Unidades de Tempo

Aplicação web que converte valores entre unidades de tempo (segundo, minuto, hora, dia, semana, mês, ano).

## 🚀 Tecnologias

- **HTML5**
- **CSS3**
- **JavaScript Vanilla**

## 📦 Como Usar

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com/Fyzz-Tech/Conversor-de-unidades-de-tempo.git
   ```
2. Abra o arquivo `index.html` diretamente em seu navegador web de preferência.
