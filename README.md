# Conversor de Unidades de Tempo

Aplicação web que converte valores entre unidades de tempo (segundo, minuto, hora, dia, semana, mês, ano).

## 🚀 Tecnologias

- **HTML5**
- **CSS3**
- **JavaScript Vanilla**

## 📦 Como Usar

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com/Fyzz-Tech/Conversor-de-unidades-de-tempo.git
   ```
2. Abra o arquivo `index.html` diretamente em seu navegador web de preferência.

## ✨ Funcionalidades

- Conversão instantânea e em tempo real
- Suporte para 9 unidades de tempo (segundo, minuto, hora, dia, semana, mês, ano, década, século)
- Botão de inversão rápida de unidades (⇄)
- Validação visual de entrada e feedback de erro
- Design moderno com dark mode, glassmorphism e animações
- Layout 100% responsivo (mobile-first)
- Alternador de tema Dark/Light com persistência local
